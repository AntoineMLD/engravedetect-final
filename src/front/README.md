## 🛠️ Fonctionnalités

- Authentification par email + mot de passe
- Canevas de dessin
- Recherche des 20 images les plus proches (modèle IA)
- Sélection des images → ajout de tags
- Ajout manuel de tags texte/chiffres
- Affichage dynamique de la liste de tags sélectionnés
- Recherche en base des verres correspondants à tous les tags
- Affichage des verres trouvés
- Détail d'un verre (infos + image complète de la gravure)
- Lien vers le monitoring (Prometheus/Grafana)
